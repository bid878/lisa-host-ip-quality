## 先说清楚，"IP 质量"到底指什么

IP 质量不是玄学，它主要看三件事：

- **IP 纯净度**：这个 IP 段在各大风控数据库里有没有被标记成数据中心、代理、VPN 或被滥用过。纯净度高的 IP，平台风控系统更倾向于把它当成普通用户，而不是机房流量。
- **原生属性**：IP 的注册地和实际出口机房是否一致。原生 IP 通常意味着平台认为你"真实位于该地区"，对解锁地区限制的内容很关键。
- **ISP 归属**：IP 是否归属于家宽运营商（住宅 IP），还是数据中心机房 IP。家宽 IP 在 TikTok、电商、广告投放这类强风控场景里通过率明显更高。

丽萨主机的产品线基本就是围绕这三个维度展开的，分双 ISP 住宅 IP 和原生 IP 两大类，覆盖美国、香港、新加坡、台湾、日本、韩国、英国、德国、越南等多个节点。

## 双 ISP 住宅 IP 和原生 IP 的区别

这是买丽萨主机最容易搞混的一点。

**双 ISP 家宽住宅 IP**：由两家运营商联合标注，IP 归属是真实家庭宽带段，平台风控看到的是一个"住在家里的普通用户"。这类 IP 是丽萨主机的核心卖点，适合 TikTok 运营、跨境电商、ChatGPT 稳定访问、流媒体解锁这类对 IP 身份敏感的场景。

**原生 IP**：IP 注册地和机房出口一致，属于"地理位置真实"，但 ISP 归属仍是数据中心。原生 IP 解锁流媒体和地区服务没问题，价格也比双 ISP 住宅 IP 低。如果你只是要看 Netflix、Disney+ 这类地区内容，不需要过家宽风控，原生 IP 套餐性价比更高。

**IP 被封了怎么办？**
